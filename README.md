# Retail Sales Performance & Insights Dashboard

## Project Overview
This project analyzes retail sales data using MySQL and Microsoft Power BI. It helps identify sales trends, profit patterns, product performance, customer behavior, and discount patterns.

## Project Objectives
- Analyze total sales, profit, and quantity sold.
- Identify top-performing products and categories.
- Compare sales across different states and cities.
- Analyze customer segments and payment methods.
- Understand discount patterns.
- Support data-driven business decisions.

## Tools Used
- MySQL – Data cleaning and SQL analysis.
- Microsoft Power BI – Interactive dashboards and visualizations.

## Project Files
- SQL File – Contains SQL queries used for retail sales analysis.
- Power BI File (.pbix) – Contains the interactive dashboard.

## Dashboard Pages
1. Retail Sales Performance Dashboard
2. Detailed Analysis
3. Sales Insights
4. Customer & Discount Analysis

## Key Business Metrics
- Total Sales
- Total Profit

- Total Quantity Sold
